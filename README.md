# PdfCraft (BEM build)

A fast, private PDF app for Windows: read, organize, combine, split and secure PDFs in a native
program written in Rust. It works on your own computer, with no account and no telemetry.

## Download

**[Download PdfCraft for Windows x64 (installer, .msi)](https://github.com/killergan/pdfcraft/releases/download/installer/pdfcraft-windows-x64.msi)**

Prefer no installation? [Portable version (.zip)](https://github.com/killergan/pdfcraft/releases/download/installer/pdfcraft-windows-x64-portable.zip): unzip it into a folder you can write to and run `pdfcraft.exe`.

- The installer is not code-signed, so Windows SmartScreen may warn on first run: choose **More info**, then **Run anyway**.
- Installed copies update themselves quietly in the background.
- Documents open as just the page, without side panels; open them from the icons on the right edge.

## About

This is a modified version of [PdfCraft](https://github.com/storytold/pdfcraft) by the ArtCraft team,
with its own icon and a simpler start-up layout. The original project is the place for the full
feature list, documentation and community.
